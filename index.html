Problem Statement

  • Presence of strong language in media content makes it unsuitable for all audiences
  • Existing systems either remove entire scenes or require manual editing
  • Subtitle-based filtering is unreliable and inaccurate
  • Lack of automated systems for precise word-level censorship

Proposed Solution

  • AI-based speech-to-text transcription using Whisper
  • Extraction of word-level timestamps
  • Detection of profanity using keyword matching
  • Selective audio muting using FFmpeg
  • Maintaining synchronization between audio and video

Technology Used

  • Python – Core processing and automation
  • OpenAI Whisper – Speech-to-text transcription
  • FFmpeg – Audio/video processing
  • Subtitle generation (SRT format)
  • GitHub Pages – Hosting presentation
